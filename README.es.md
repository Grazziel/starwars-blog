# Blog de Star Wars

Aplicación web construida con **React** y **Context API** que muestra personajes, vehículos y planetas del universo Star Wars, con un sistema de favoritos accesible desde toda la app. Consume datos en tiempo real de [SWAPI.tech](https://www.swapi.tech/documentation) y se integra con el backend [starwars-api](https://github.com/Grazziel/starwars-api).

## Stack técnico
- React + React Router
- Context API (estado global de favoritos)
- Bootstrap (componentes de UI)
- Imágenes vía [starwars-visualguide.com](https://starwars-visualguide.com)

## Funcionalidades
- Vista principal con tarjetas de personajes, vehículos y planetas
- Vista de detalle por cada entidad
- Botón de favoritos accesible desde toda la aplicación (navbar)
- Persistencia de favoritos en localStorage

## Cómo correrlo localmente
\`\`\`bash
npm install
npm start
\`\`\`
